Published: 2026-11-15, 17:03:20 UTC, at the user's request, as Latest. Release: [WrongMemory v0.3.1](https://github.com/WrongStack/wrongmemory/releases/tag/v0.3.1).

Source commit: `7d751955472144b6780fb6618bc5892e2d7e41b0` (merge of PR #7 into `main`). Annotated tag object: `fec45756c8c3cd668ae486dd3dd88dda6c28f9a2`. The tree is identical to `61decb8`, the commit tested on the PR branch.

The only change from v0.3.0: writes, maintenance and library queries work on SAGE stores that lack the optional `memories.unicode_text` column. Before, every write to such a store failed with `INTERNAL: table memories has no column named unicode_text`. No DDL is applied to adopted stores. Details: [docs/status.md](../status.md).
