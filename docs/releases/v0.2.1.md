Initial Windows library/relations rendering was observed earlier, but current controls were verified through code/model/IPC tests rather than renewed screen automation. Full accessibility/IME/high-DPI/GPU fallback/sleep-resume/frame-performance acceptance remains NOT RUN. No new named MCP-client certification, native 1.0 certification or continuous 24-hour service soak is claimed. Earlier evidence and remaining gaps remain in the status/evidence matrix.
