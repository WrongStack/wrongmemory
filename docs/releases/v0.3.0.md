## Acceptance boundary

An unsigned preview: no Authenticode signature, no Apple notarization. The macOS desktop has run on hosted CI runners only (builds, tests, LaunchServices launch of the bundle, rendered screenshots), not in hands-on use. Linux rendering was verified under X11 (WSLg, Xvfb); native Wayland rendering, launching from a desktop environment's menu, Start Menu search/pinning and taskbar grouping, accessibility, IME, high DPI, GPU fallback, sleep/resume and sustained frame performance are NOT RUN. No MCP-client certification, native 1.0 certification or SAGE parity beyond earlier evidence is claimed.
